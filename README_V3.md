# 公募基金高频仓位测算 —— 数据准备与运行

复现东吴证券《共识的力量》（20260519）的"补截面+补时序"框架——用重仓股行业补全法构建季度模拟组合，再用带约束的时间加权 Lasso 净值回归升频到周频，输出隐含行业仓位曲线、披露间隔内的隐性调仓、风格漂移预警和与季报的对账。

行情口径：**申万一级（31 个行业）**，全部免费源。研报本身也测过申万口径，结论一致。

---

## ⚠️ 一个必须先说的坑（否则结论会错一半）

**绝不能直接用东财"累计净值"(nav_cum) 算基金日收益。**

东财累计净值 = 单位净值 + 历史累计分红（简单加总，**不复利**）。对分红多的老基金，累计分红可占净值一半以上，导致累计净值分母被放大，日收益波动率被压缩约一半，回归 Σβ 会被**系统性腰斩**。

实测（161005 富国天惠，16 次分红）：
- 用 `nav_cum` 算收益 → β ≈ **0.40**（错，权益仓位被估成 ~40%）
- 用 `nav_unit` 算收益 → β ≈ **0.82**（对，对应披露 ~90% 权益）
- 用 `nav_adj`（单位净值 + 除息日分红加回，红利再投资）→ β ≈ **0.82**（最准）

正确做法：被解释变量用 **`nav_adj`**，回归代码默认优先用它。

### stock_level 穿透（可选，仅 FULL 模式）

用基金自家持股行情替代行业指数作为回归因子：

```bash
python fetch_stock_klines.py <代码>      # 补全个股 K 线缓存（首次 ~2 分钟，后续秒级）
python run_analysis.py <代码> --stock-level
```

**关于选哪个口径**：`--stock-level` 和默认的 `index_proxy` 各有优劣势——分布式基金（100 只持仓，如 161005）`index_proxy` 的行业指数分散化平滑噪声，R² 反而更高；集中式基金（极致行业型）stock_level 可能更准。实测后选择留一法 MAE 更低的那个。**不要预设答案。**

## 六、读报告的铁律

1. **先看第 0 节可信度评级（A/B/C/D）**——综合考量运行模式、R²、MAE、标定方式。C 及以下谨慎使用。
2. **制造业约束是虚的。** 季报 "C 制造业"是一整行（通常 50-70%），电子/电新/医药/机械之间怎么分没有约束力。
3. **"近 4 周隐性调仓"先看噪声带**——落在 1.5σ 内的变动极可能是估计波动。
4. **Σβ 中位数是体检项**——显著低于披露权益仓位先查净值口径。
5. **这是重建不是复刻**——研报参数全隐去，数字对不上是必然的。

## 七、已知局限（方法固有，非 bug）

- 不能还原真实持仓，只能给收益口径暴露
- 不能做 FACT 择时/行业轮动（需全市场几千只基金，另一个量级）
- stock_level 路径仅 FULL 模式可用，分布式基金通常 index_proxy 更优
- 免费源无中证全指成分权重，缺失 overweight 指标
- 详情见 `AUDIT_REPORT.md`
